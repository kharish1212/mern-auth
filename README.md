## 🚀 Installation & Setup

### 1️⃣ Clone Repo
```sh
git clone https://github.com/kharish1212/mern-auth.git
cd mern-auth
```

### 2️⃣ Install Frontend
```sh
cd client
npm install
npm run dev
```

### 3️⃣ Install Backend
```sh
cd server
npm install
npm start
```

---

## 🔑 Environment Variables  
Create `/server/.env`:

```
MONGO_URI=your_mongodb_link
JWT_SECRET=your_secret
EMAIL_USER=your_email
EMAIL_PASS=your_email_password
```
